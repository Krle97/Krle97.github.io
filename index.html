Script language

Schedule (one line, optional):
@every 3m run repeatedly · @after 8h run once · @manual only with “Run” (default) · @disabled never scheduled

Commands:
KEY GUI R press keys together (modifiers + up to 6 keys)
TEXT hello world type the rest of the line (US layout, ASCII)
DELAY 300 wait; plain = ms, or 2s, 1m
REPEAT 3 … END repeat a block
# comment

Durations: ms s m h, combined like 1h30m. For @every/@after a plain number is seconds.

Keys: letters/digits/symbols (r, 5, /), ENTER ESC TAB SPACE BACKSPACE DELETE INSERT HOME END PAGEUP PAGEDOWN UP DOWN LEFT RIGHT F1–F12 NUMLOCK CAPSLOCK SCROLLLOCK PRINTSCREEN PAUSE MENU
Modifiers: CTRL SHIFT ALT GUI (=WIN), RCTRL RSHIFT RALT RGUI

Example:

@after 30s
KEY GUI R
DELAY 300
TEXT notepad
KEY ENTER
DELAY 1s
TEXT Hello!

Start/Stop/Pause only last until the PC is unplugged. Use @disabled to switch a script off permanently.
